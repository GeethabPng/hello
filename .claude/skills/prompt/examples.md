# דוגמאות לפרומפטים לפי קטגוריה

## כתיבת תוכן

### דוגמה 1 — פוסט לינקדאין

**רעיון גולמי:** "אני רוצה לכתוב פוסט על מוצר חדש"

**פרומפט מוכן:**
```
אתה כותב תוכן מקצועי ברשתות חברתיות עם ניסיון בשיווק B2B.

כתוב פוסט לינקדאין על השקת המוצר [שם המוצר] — פתרון [תיאור קצר מה הוא עושה].

קהל היעד: מנהלי [תפקיד] בחברות [גודל/סקטור].

הפוסט חייב:
- להתחיל בשורה פותחת חזקה שמושכת תשומת לב (hook)
- להסביר בבעיה שהמוצר פותר תוך 2-3 משפטים
- לכלול תוצאה/ערך מוכח אחד (מספר או עובדה)
- לסיים ב-CTA ברור
- אורך: 150-200 מילים
- טון: מקצועי אך אנושי, לא שיווקי-מדי

אל תשתמש בביטויים שחוקים כמו "excited to announce" או "thrilled to share".
```

### דוגמה 2 — אימייל ללקוח

**רעיון גולמי:** "אני צריך לכתוב אימייל ללקוח שלא שילם"

**פרומפט מוכן:**
```
אתה מנהל חשבונות בחברה עם ניסיון בגבייה עדינה.

כתוב אימייל תזכורת לתשלום לחשבונית שעברו [X] ימים מתאריך הפירעון.

פרטים:
- שם הלקוח: [שם]
- סכום: [סכום]
- מספר חשבונית: [מספר]

הטון צריך להיות: נעים ומקצועי — לא עוין, אבל ברור לגבי הציפייה לתשלום.

מבנה האימייל:
1. פתיחה ידידותית (שורה אחת)
2. תזכורת ידידותית על החשבונית
3. פרטי תשלום ברורים
4. הצעה לעזרה אם יש בעיה
5. סגירה חיובית

אורך: קצר — לא יותר מ-150 מילים.
```

## קוד ופיתוח

### דוגמה 1 — כתיבת פונקציה

**רעיון גולמי:** "אני צריך קוד שמסנן רשימה"

**פרומפט מוכן:**
```
אתה מפתח Python בכיר עם דגש על קוד נקי וקריא.

כתוב פונקציה ב-Python שמסננת רשימה של מילונים (list of dicts) לפי ערך של מפתח נתון.

דרישות:
- הפונקציה מקבלת: רשימה, שם מפתח (key), ערך לסינון
- תומכת בסינון חלקי (contains) ובסינון מדויק (exact match)
- מחזירה רשימה חדשה (לא משנה את המקורית)
- כוללת type hints
- כוללת docstring קצר
- Python 3.9+

כתוב גם 3 דוגמאות שימוש שממחישות את הפונקציה עם קלט ופלט צפוי.
```

---

### דוגמה 2 — Code Review

**רעיון גולמי:** "אני רוצה שמישהו יבדוק את הקוד שלי"

**פרומפט מוכן:**
```
אתה מפתח בכיר המבצע סקירת קוד מקצועית.

סקור את הקוד הבא ותן פידבק מובנה:

[הדבק את הקוד כאן]

בדוק ודווח על:
1. **באגים פוטנציאליים** — בעיות לוגיות, edge cases לא מטופלים
2. **ביצועים** — בעיות אפשריות עם נתונים גדולים
3. **אבטחה** — SQL injection, XSS, חשיפת מידע רגיש
4. **קריאות** — שמות משתנים, ארגון קוד, comments
5. **שיפורים מוצעים** — עם קוד לדוגמה

פורמט: כל ממצא עם: [דרגת חומרה: גבוה/בינוני/נמוך] + הסבר + קוד מתוקן.
```

## ניתוח ומחקר

### דוגמה 1 — ניתוח נתונים

**רעיון גולמי:** "אני רוצה לנתח את הנתונים שלי"

**פרומפט מוכן:**
```
אתה אנליסט נתונים בכיר המתמחה בהצגת תובנות עסקיות.

נתח את הנתונים הבאים ותן לי תובנות אקציונביליות:

[הדבק את הנתונים / תיאור הנתונים כאן]

ענה על השאלות הבאות:
1. מהם 3 הממצאים הבולטים ביותר?
2. האם יש מגמות חריגות שדורשות תשומת לב?
3. מה המלצתך לצעדים הבאים?

פורמט הפלט:
- סיכום מנהלים: 3-4 משפטים
- ממצאים: רשימה ממוספרת עם נתונים תומכים
- המלצות: עם סדר עדיפויות

רמת הסבר: מותאם למנהל שאינו מומחה טכני.
```

---

### דוגמה 2 — השוואת אפשרויות

**רעיון גולמי:** "אני רוצה להשוות בין שתי אפשרויות"

**פרומפט מוכן:**
```
אתה יועץ אסטרטגי אובייקטיבי.

השווה בין [אפשרות A] ל-[אפשרות B] עבור [הקשר / מטרה].

קריטריונים להשוואה:
- [קריטריון 1, למשל: עלות]
- [קריטריון 2, למשל: זמן יישום]
- [קריטריון 3, למשל: סיכון]
- [קריטריון 4, למשל: סקלביליות]

הקשר שלי: [מה חשוב לי במיוחד]

פורמט:
1. טבלת השוואה
2. יתרונות/חסרונות של כל אפשרות
3. המלצה מנומקת ברורה
```

## הסבר וחינוך

### דוגמה 1 — הסבר מושג

**רעיון גולמי:** "אני רוצה שיסבירו לי מה זה machine learning"

**פרומפט מוכן:**
```
אתה מורה מנוסה שמסביר נושאים טכניים מורכבים לאנשים ללא רקע טכני.

הסבר מהו Machine Learning לאדם שעובד ב[תחום] ואין לו רקע בתכנות.

ההסבר צריך:
- להתחיל באנלוגיה מחיי היום יום
- להסביר את הרעיון המרכזי ב-2-3 משפטים פשוטים
- לתת 2-3 דוגמאות מוחשיות מהחיים האמיתיים
- להסביר למה זה רלוונטי ל[תחום] שלהם
- לא להשתמש בז'רגון טכני ללא הסבר

אורך: קצר — 200-300 מילים.
אל תשאל שאלות חוזרות — תן הסבר שלם ומובנה.
```

## סיעור מוחות

### דוגמה 1 — רעיונות לעסק

**רעיון גולמי:** "אני צריך רעיונות לשיווק"

**פרומפט מוכן:**
```
אתה מנהל שיווק יצירתי עם ניסיון בסטארטאפים.

צור 10 רעיונות שיווק עבור [תיאור המוצר/שירות] המיועד ל[קהל יעד].

אילוצים:
- תקציב חודשי: [סכום] ₪
- משאבי צוות: [X] שעות בשבוע
- ערוצים זמינים: [ערוצים, למשל: אינסטגרם, אימייל, אירועים]

לכל רעיון ציין:
- תיאור קצר (2-3 משפטים)
- עלות משוערת
- זמן לתוצאות ראשונות
- רמת קושי: קל/בינוני/מאתגר

דרג את הרעיונות מהמיידי ביותר לביצוע עד למורכב ביותר.
```

## יצירה

### דוגמה 1 — כתיבת סלוגן

**רעיון גולמי:** "אני רוצה סלוגן לעסק שלי"

**פרומפט מוכן:**
```
אתה קופירייטר יצירתי עם ניסיון במיתוג.

צור 8 סלוגנים עבור [שם העסק] — [מה העסק עושה].

ערכי המותג: [למשל: אמינות, חדשנות, נגישות]
קהל יעד: [תיאור הקהל]
טון: [למשל: רציני, שובב, מעצים]

לכל סלוגן הסבר בקצרה מה הרעיון שמאחוריו ולמה הוא עובד.

הצע גרסאות ב:
- עברית
- אנגלית
- מיקס (עברית + מילה/ביטוי באנגלית)
```

---

### דוגמה 2 — כתיבת סיפור קצר

**רעיון גולמי:** "אני רוצה סיפור קצר"

**פרומפט מוכן:**
```
אתה סופר/ת בעל/ת קול ייחודי המתמחה בסיפורים קצרים.

כתוב סיפור קצר עם המאפיינים הבאים:

- ז'אנר: [למשל: מותחן, רומנטי, מדע בדיוני]
- דמות ראשית: [תיאור קצר]
- הגדרה: [מקום וזמן]
- קונפליקט מרכזי: [מה הדמות צריכה להתמודד איתו]
- סיום: [פתוח / מפתיע / מרגש]
- אורך: [X] מילים

שים לב ל:
- פתיחה שמושכת מיד לתוך הסיפור
- דיאלוג טבעי (אם יש)
- תיאורים חושניים שיוצרים אווירה
- קצב שמשתנה בהתאם למתח
```
